# Habloom

小さな習慣を積み重ね、自分の成長を育てる習慣化アプリ。

名前は **habit（習慣）** と **bloom（花開く）** を組み合わせています。

## プロジェクトの状態

要件定義を終えた段階です。アプリの実装はまだありません。

- **対象プラットフォーム**: iOS を最初にリリースし、その後 Android に対応します。
- **MVP の機能**: 習慣の登録、日々のチェック、継続日数の表示、リマインダー通知、統計・履歴。データは端末内に保存します。
- **MVP の後**: サーバー同期と認証を追加し、端末間でデータを同期できるようにします。
- **技術構成**: 共通コアを Rust で書き、UniFFI を介して Swift(SwiftUI)と Kotlin(Jetpack Compose)のアプリから利用します。
- **ライセンス**: Apache License 2.0 を採用する予定です。

詳細と未決定事項は [docs/requirements.md](docs/requirements.md) を参照してください。
